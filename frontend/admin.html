📧 Envío de correos a contratistas

Instrucciones: Copia desde tu sistema (Excel, nube, etc.) los datos de contratistas y pégalos abajo. El sistema detectará automáticamente la cédula y el correo de cada línea.

ℹ️ ¿Cómo funciona?

El sistema comparará la cédula con el Excel de contratistas. Si existe → enviará la plantilla "SIN REGISTRO" (solo documentos).
Si NO existe → enviará la plantilla "CON REGISTRO" (portal + documentos).

📌 Cada línea debe tener: Cédula + Correo (separados por tabulador, coma o punto y coma) Líneas: 0
ℹ️ ¿Cómo funciona?

El sistema enviará el mismo correo a todos los destinatarios, sin comparar cédulas. Útil cuando solo tienes los correos.

📌 Cada línea debe tener un correo electrónico Líneas: 0
